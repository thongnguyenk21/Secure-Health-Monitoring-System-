# CLAUDE.md

Guidance for Claude Code in this repository.

## Read first

- `docs/history/2026-10-15-design-review-session.md`: decisions, working rules and open items from the latest design review with the project owner. Read it before you change the report slides, the C4 page or the design documents.
- `docs/design/DECISIONS.md`: the decision log. Newer entries override older ones (D22–D31 supersede parts of D1, D16, ADR-0007 and the Pi 3B+ target).
- `docs/specs/JD.md`: the project requirement.

## Repo conventions

- Git Flow and commit format: `CONTRIBUTING.md`.
- Code and documentation rules: `docs/engineering/CODING_CONVENTIONS.md`. Do not add tool attribution trailers to commits.
- Slides: edit `docs/reports/system-design-slides.html`. Do not regenerate the PDF or PNG exports until the owner approves the slides.
